- `newspaper.webp`: `B2_L3_EN_001_1.jpg`
- `menu.webp`: `C1_L3_ZH_001_1.jpg`
- `poster.webp`: `A3_L3_ZH_001_1.jpg`
- `receipt.webp`: `C2_L3_EN_001_1.jpg`
- `code.webp`: `E4_L3_EN_001_1.jpg`
- `comic.webp`: `F3_L3_ZH_001_1.jpg`

The derivatives retain the original 1024 × 1024 dimensions, encoded as WebP at quality 87. `social-card.jpg` combines these existing paper examples with the project title. `favicon.svg` is a typographic project mark.
